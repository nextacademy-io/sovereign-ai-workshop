# Reference results

Measured results from the trainer's validation runs on the workshop GPU. They are **read-only reference
material**: use them to check your own numbers, or as a fallback when your own run failed.

`./scripts/reset.sh lab-03` (and later labs) copies the relevant results here on your machine. Every file
carries its provenance (hardware, model revision, engine version, server arguments, date); your own results are
in `benchmark/results/mine/`.
